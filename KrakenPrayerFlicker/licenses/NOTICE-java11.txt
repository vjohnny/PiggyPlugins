kraken-prayer-flicker-runelite-java11.jar

This jar bundles the Kraken Prayer Flicker plugin with Kraken API 5.4.1, compiled
for Java 11 (class file version 55), so it can be sideloaded in vanilla RuneLite
running on a Java 11 JRE. Kraken API is loaded from its own hooks.json resource.
No hook names were rewritten. hooks.json is the unmodified 5.4.1 resource.

Modifications to Kraken API 5.4.1 (GNU GPL v3, section 5):
The Java sources are the unmodified files from tag 5.4.1
(https://github.com/Kraken-Plugins/kraken-api/tree/5.4.1). They are vendored at
KrakenPrayerFlicker/kraken-api-java11/src. The only change from the upstream build
is how those sources are compiled: javac --release 11 instead of the upstream Java
17 toolchain. That patch is KrakenPrayerFlicker/kraken-api-5.4.1-java11.patch.
No statements, hook names, or resources were edited. The published 5.4.1 jar is
Java 17 bytecode (class file version 61) and does not load on Java 11.
